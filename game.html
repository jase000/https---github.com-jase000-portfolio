tema 04 - spil animation

game

clicking game with animations

Game design with animations and illustrated assets

The objective of the game is to collect as many falling pink diamonds as possible while avoiding the hitting the rats. The game ends when the timer runs out or the player loses all 3 lives.

illustrated assets

This project introduced me to designing my own game assets in Adobe Illustrator. I created everything from UI buttons and game characters to background illustrations. This taught me an efficient workflow between Illustrator and VSCode that allowed me to move fast from drawing and refining assets to quickly implementing and testing them within the game.

js and css animations

I learned a lot about javascript and the underlying game mechanics needed to make a fun and playable game. We created a flow of multiple js functions such as EventListeners waiting for clicks that triggers new functions, points/life updates, classlists getting removed/added, and end-game mechanics. One big takeaway for me from this project is to always make sure to outrule every possibilities for the user getting stuck or the game breaking. Furthermore, I worked a lot with css animations to make elements in the game move.

work process

Throughout theme 04 - Animation - I learned several new tools and techniques. For example, I created state machine diagrams to plan the flow and user paths through my game. Moving forward, I can apply these tools to other types of interactive websites, not just games. We also focused on creating engaging visual designs with interactive and eye-catching UI elements, design conventions, and animation techniques to guide and engage the user.
