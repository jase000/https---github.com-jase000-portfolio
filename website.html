tema 05 - website redesign

website

website design for a vintage store.

For this task we redesigned a website for a local vintage clothing shop

We wanted to design a website that captured the vibrant and retro aesthetics costumers experience when entering the physical store. In our opinion the shop's current website didn't live up to the vibe and feel of the physical shop and their brand. Since we were working with a physical vintage clothing shop we wanted to create, not a webshop, but a website that told it's story.

good retro vibes

It was important for us to capture the vibe of the physical store. Therefore we started everything with brainstorming keywords and creating moodboards that we thought represented the brand. Some keywords were retro, 70's america, vintage, and warmth. We made a likert test on three moodboards to understand which feelings they evoked in the user. This gave us the foundation for creating our style tile and visual identity moving forward.

sketch to final product

Before making the actual website we created multiple sketches of wireframes. After settling on a composition we moved on to creating a LOFI prototype to better visualize the website. After that we created a clickable HIFI prototype in figma which we did a "think-out-loud" test to understand if the user found the website intuitive. Once we had a tested and proven prototype we could begin the coding process.

work process

This project introduced me to working on a bigger creative task in a group. We used work tools like Trello to structure our work tasks and deliveries within the group. We held many scrum meetings discussing what tasks, roadblocks and goals we had for the day. For the coding part we made a GitHub repository that we could collaborate on within the team. We did run into some roadblocks with illness and a computer breaking down so being able to help and takeover teammember's code served us well.
Together with another group we made a heuristic test on our website. This helped us notice flaws and design improvements.
