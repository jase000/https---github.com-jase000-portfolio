responsive website design

Making a responsive design with basic html and css

This was one of our introduction themes on our 1. semester. Here we learned about the fundamental principles of web development. We focused on html and css, and learned about wireframes, responsiveness, images, html validation, and folder structure.

mobile-first design

The objective of the project was to create a simple and responsive website. The design structure was given by our teachers and they provided us with the html needed. We focused on mobile-first design

key takeaways

Other than being a good introduction to web development this project taught me about working from a wireframe and layout diagram. This was a great way to quickly visualize the structure and layout of a website. We also worked with diffenent html tags such as body, header, main, section, and footer. We learned about the collaboration between html and css, and the importatance of classes.
