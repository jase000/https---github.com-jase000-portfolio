tema 03 - grundlæggende UI/UX

colorpage

random color palette generator

This website lets users generate random combinations of colors and see them against eachother.

After the user has generated a color combination the site explores the colors used for copy. Here various combinations of headers, subheaders and body text are created.

javascript

This project introduced me to working in javascript. Creating the script for the random color picker required me to first create a number generator that converts random numbers to 16 string hex codes. These values are immediately displayed on the site and saved in the user's session storage as the user navigates around the website.

p5.js

to generate the visuals for website a background animation was created in p5.js tracking the users cursor and interacting with blocks and shapes around it.

work process

In theme 03 - basic UI/UX - we were assigned to code a website on a topic of our own choice, based on something we found personally interesting. The focus of this course was to work through the entire process from idea to a concrete, finished product. My workflow included researching an idea, creating and testing a digital prototype in Figma, coding my own website using HTML, CSS, and JavaScript, and finally presenting the completed website along with the process behind it. In addition to gaining new coding experience, the course taught me a lot about how to turn an idea into a well-executed final product.
